Genome browsers, structure viewers, Galaxy and notebooks were built for research. Students can use the same tools on real data from their first year, and they get more from them when the activity is designed around a clear question. These pages help with that design: which tool suits which learning outcome, how to structure the session so students know what to look for, how to assess the result, and which misunderstandings to expect.

## Topics

Each topic page has the same parts: what the tool teaches well, activities with a level and a timing, ideas for assessment, common misconceptions, practical tips, and references. Each one links to its partner page for developers, where you can try the examples live and download them.

## About the evidence

Where a page says that an approach works, it cites a study, and we have checked that each reference exists and says what we say it says. The evidence is uneven. There is good research on active learning in general and on how students read evolutionary trees, but there are few classroom studies of genome browsers, network viewers or code in the browser. Where the evidence is thin, the pages say so, and their advice comes from teaching experience.
