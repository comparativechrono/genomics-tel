Teach genomics with the tools researchers use

Guides for educators and developers on genome browsers, alignments, 3D structures, networks, Galaxy, R and Python in the browser, phylogenetic trees and charts. Every topic has live examples, and every example has code you can copy.

For educators What each tool is good for in class, activities to run with it, and the evidence behind them. For developers How to put each tool into your own teaching pages, with working examples.

Eight topics, each seen from two sides

Each topic has a page for educators, on what the tool is good for in class and how to run an activity with it, and a page for developers, on how to build it into a web page. Each page links to its partner.
