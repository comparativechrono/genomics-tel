Technology enhanced learning (TEL) for genomics

Teach genomics with the tools researchers use

These guides are for educators who want to use research tools in their genomics teaching, and for developers who build teaching websites. They cover genome browsers, alignments, 3D structures, networks, Galaxy, R and Python in the browser, phylogenetic trees and charts, and every topic comes with live examples whose code you can copy.

For educators Find out what each tool is good for in class, try activities that use it, and see the evidence behind them. For developers Learn how to build each tool into your own teaching pages, starting from working examples.

What the guides cover

The site covers eight topics, and each has two pages. The page for educators is about using the tool in class: what it is good for, and how to run an activity with it. The page for developers is about building the tool into a web page. Each page links to the other, so you can move between them.
